# Soil-health

A namespace for soilwise assets.

[gh-pages branch](https://soilwise-he.github.io/soil-health) contains the content of <https://soilwise-he.github.io/soil-health-knowledge-graph> rendered in html.
Html is generated with [widoco](https://github.com/dgarijo/Widoco), using [github actions](https://github.com/soilwise-he/soil-health/blob/main/.github/workflows/widoco.yml).
